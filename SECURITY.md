# Politique de sécurité

## Versions prises en charge

La version actuellement maintenue du plugin bénéficie des correctifs de sécurité.

Les anciennes versions peuvent ne plus recevoir de correctifs.

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans ce projet, merci de ne pas ouvrir d'Issue publique.

Utilisez de préférence la fonctionnalité de signalement privé des vulnérabilités proposée par GitHub afin de transmettre les informations de manière confidentielle.

Merci d'indiquer, si possible :

- une description claire de la vulnérabilité ;
- les fichiers ou fonctionnalités concernés ;
- les étapes permettant de reproduire le problème ;
- l'impact potentiel ;
- toute proposition de correction éventuelle.

Le signalement sera analysé dès que possible.

Si la vulnérabilité est confirmée, un correctif sera préparé, testé puis intégré au projet avant toute divulgation publique.

Merci de ne pas publier publiquement les détails d'une vulnérabilité avant sa correction.
