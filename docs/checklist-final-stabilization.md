# Checklist visuelle de préproduction

Tester le shortcode `/ajouter-licencie/` et l’onglet `#add_licence` avec JavaScript activé puis désactivé.

| Largeur | Attendu |
|---:|---|
| 1440 px | Contenu centré de 1200 px, deux colonnes équilibrées, actions horizontales. |
| 1280 px | Largeur utile sans débordement ni grande zone blanche. |
| 1024 px | Deux colonnes lisibles, champs et textes non comprimés. |
| 768 px | Une colonne, blocs santé/actions pleine largeur, boutons empilés. |
| 375 px | Champs et boutons pleine largeur, aucun mot coupé verticalement. |

Vérifier aussi la saison `2026-2027`, l’absence de `2027-2028`, le diagnostic administrateur WooCommerce, le message public neutre et le remplacement d’un document refusé sans suppression de l’ancienne pièce.
